跨设备

Windows、Mac 或下一台电脑，都从同一个私人仓库获得最新上下文。

跨 Agent

核心记忆是普通 Markdown，不属于 Codex、Claude 或任何单一厂商。

可追溯

每次改动都有历史；冲突时保留双方，由你决定什么才是最新事实。

普通用户，只做三件事

01
复制提示词

点击上面的按钮，把完整内容发给一款能操作本机文件的 Agent。

02
完成官方授权

只在 GitHub 官方页面登录。其余工具、目录、文件和仓库由 Agent 处理。

03
把接入提示词发给第二台电脑

两边回答同一个项目问题，答案一致，才算真正接通。

隐私提醒：公开的是空模板，你的个人记忆必须放在另一个 Private 仓库。密码、API Key、Token、验证码、证件、银行卡和其他高敏感信息不要写入。Private 也不等于可以无边界收集。

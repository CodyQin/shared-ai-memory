# 新设备接入提示词

通常安装助手会自动生成一份已经填好仓库地址的版本。如果没有，就把下面内容发给新设备上的本地 Agent，并只替换尖括号中的私有仓库 URL。

---

请帮我把这台设备接入我的 Shared AI Memory 私有仓库：`<PRIVATE_REPOSITORY_URL>`。

我不是技术用户。请你实际完成接入，不要只给 Git 教程，也不要让我手动输入命令。先用简短的话说明将做什么，再执行：

1. 识别系统、当前 Agent 和适配方式，生成匿名设备代号。
2. 检查 Git 与 GitHub CLI；缺失时只从官方来源安装并先征得我确认。
3. 使用 GitHub 官方网页/设备授权登录；绝不向我索取密码、验证码、Token 或私钥。
4. 在不覆盖现有目录的前提下克隆仓库。
5. 通过 GitHub API 或 CLI 明确验证仓库为 PRIVATE；不是 Private 或无法验证就停止。
6. 阅读仓库中的 `README.md`、`USER.md`、`MEMORY.md`、`PROJECTS.md`、相关 `memory/topics/`、`skills/shared-memory/SKILL.md`。
7. 为当前 Agent 安装最薄的入口适配；不要复制出第二套个人记忆。
8. 做敏感信息扫描和系统自检，不要把秘密打印出来。
9. 用不超过 5 条内容告诉我：你已经了解了我什么、当前项目做到哪里、这台设备以后如何开始和结束工作。

如果目录已存在或本地有修改，不得覆盖、删除或强制重置；先解释并提供安全选项。
